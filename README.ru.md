# 🛠️ YOLO Swiss Army Knife (YSAK)

<p align="center">
  <strong>Швейцарский армейский нож для подготовки и деплоя YOLO-моделей</strong>
</p>

<p align="center">
  Устали вручную конвертировать модели, писать временные Python-скрипты для экспорта, запускать консольные команды и проверять детекцию «на глаз»? 
  <br>
  <strong>YOLO Swiss Army Knife (YSAK)</strong> — это графический ассистент, который берет на себя всю рутину по оптимизации, постобработке и локальному тестированию моделей YOLO (Ultralytics).
</p>

## 🚀 Ключевые возможности

### 1. 📊 Менеджер запусков (Model Manager / Runs)
Больше не нужно блуждать по папкам `runs/detect/train*`. Приложение сканирует вашу рабочую директорию, визуализирует графики обучения (mAP50, loss, recall) прямо в интерфейсе и держит все ваши тренировочные запуски под рукой.

### 2. ⚙️ Продвинутый профильный мульти-экспорт
Забудьте про ограничения экспорта одной галочкой. Настраивайте гибкие профили для пакетной конвертации в **ONNX, OpenVINO, TensorRT** и другие форматы:
* Одновременный экспорт в разных разрешениях (imgsz: `320`, `640`, `1280` с шагом 32).
* Раздельное переключение прецизионов (**FP32, FP16, INT8**) кнопками.
* Интеграция узла **NMS** (Non-Maximum Suppression) в граф модели.
* Оптимизация и упрощение графа через `onnx-simplifier`.

### 3. 🔌 Автоматическая инжекция ByteBGR
Специфическая и мощная фича для С++ / C# production-решений. Приложение умеет автоматически встраивать в ONNX-модель предобрабатывающий узел **ByteBGR** (через утилиты `NeuroModFlowNet.ONNX`). Модель начинает принимать на вход сырой байтовый поток `uint8` напрямую с камер без необходимости писать код нормализации на стороне клиента.

### 4. 🛠️ Автоматизация Post-Export пайплайнов
После экспорта часто требуется скопировать файл в рабочую папку проекта или отправить на удаленный сервер. Настройте список `post_exports` в конфигурационном файле, и YSAK автоматически запустит нужные вам цепочки скриптов (`.ps1`, `.bat`, `.cmd` или системные команды), передав им пути к новым моделям.

### 5. 🎯 Мгновенный тест-инференс (Inference Preview)
Проверьте результат экспорта прямо в приложении! 
* Выберите сгенерированную модель, укажите тестовое изображение из папки проекта и мгновенно оцените результат.
* Поддержка различных типов задач YOLO (стандартная детекция **Detect**, ориентированные рамки **OBB**, ключевые точки **Pose**).
* Отрисовка результатов силами высокопроизводительной библиотеки `NeuroModFlowNet.ONNX` на C# ONNX Runtime.

## 🛠️ Системные требования и зависимости

* **Платформа:** Windows 10/11
* **Среда выполнения:** .NET 10.0 + среда выполнения Avalonia UI (встроена)
* **Внешние инструменты:** 
  * Установленный в системе Python с пакетом `ultralytics` (для работы экспортера).
  * `NeuroModFlowNet.ONNX.Tools` в системном `PATH` (для инжекции ByteBGR).

## 📦 Быстрый старт

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/KOE73/yolo-swiss-army-knife.git
   ```
2. Откройте проект в Visual Studio 2022 или JetBrains Rider и соберите решение, либо выполните сборку через CLI:
   ```bash
   dotnet build -c Release
   ```
3. Запустите собранное приложение: `YoloHelperApp.exe`.
4. Укажите вашу рабочую директорию проекта YOLO (папку, содержащую папки `images`, `runs`, файлы конфигурации).
